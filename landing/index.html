First launch: how to get past “Apple could not verify”

macOS shows this on any app that isn’t signed with a paid Apple Developer ID. Mac Cleanup is safe — Apple just hasn’t verified it. Any of these fixes work:

Option 1 · System Settings (any macOS version)

  1. Click Done on the warning dialog.
  2. Open System Settings → Privacy & Security.
  3. Scroll to the bottom — you’ll see “Mac Cleanup was blocked to protect your Mac”.
  4. Click Open Anyway → enter Touch ID / password.

Option 2 · Terminal (fastest — 10 seconds)

  1. Open Terminal (Cmd + Space → type “Terminal”).
  2. Paste and press Return: 
    xattr -cr /Applications/Mac\ Cleanup.app
  3. Double-click Mac Cleanup normally. Warning is gone forever.

Option 3 · Right-click Open (older macOS)

  1. In Finder → Applications → right-click Mac Cleanup → Open.
  2. The dialog will show an Open button. Click it.
  3. (If Sonoma/Sequoia hides the Open button — use Option 1 or 2.)

Why this is needed: until we buy an Apple Developer certificate ($99/yr), macOS treats Mac Cleanup as “unidentified”. The app itself is unchanged either way.
